# Visa Atlas v2.0 · 极简球体地图设计规范

目标：**一屏之内只有「一个地球 + 一个搜索框」**。功能通过地图交互、搜索预置词和悬浮卡片进入，不再有三栏面板、筛选器列表和结果卡片墙。

## 1. 视觉基调

- 背景：`#05080b`（近黑），中央地球的海洋 `#0e1a22`（极低饱和蓝灰），大气边缘由 MapLibre sky 自然形成。
- 陆地：低饱和灰 4 档（`#30363a / #343a3e / #2c3236 / #383e42`），只做极轻微区分；国境线 `#5a636a`，随缩放 0.7→1.2px。
- 国家未选中 = 以上灰色；**hover / selected = 高饱和黄 `#DFC11D`（选中略亮 `#E3C31C`）**，边界 `#F6DD55` + 轻微外发光。参考图色号。
- UI 文字：`#E8EAEC`；次级 `#8B949A`；发丝线 `rgba(255,255,255,.10)`。
- 字体：Fraunces Variable（英文/数字标题）+ Manrope Variable（UI）+ 系统中文字体；中文标题可回退到衬线（Songti SC）。
- 所有 UI 浮层：深色半透明 `rgba(9,13,16,.72)` + 12px blur + 1px 发丝线 + 大圆角；不使用实心白底/彩色卡片墙。

## 2. 布局（1440×900 基准）

```
┌──────────────────────────────────────────────────────────────────┐
│ ◎ VISA ATLAS                         [ 搜索胶囊 + 预置词 ]   ⓘ  │
│                                                                  │
│                                                                  │
│                          G L O B E                               │
│                                                                  │
│                          （全屏铺满）                             │
│                                                                  │
│ 拖拽旋转 · 滚轮缩放 · 点击国家          （hover 卡片）      + − ◎ │
│ 249 个目的地 · 数据更新 2026-11                             提示  │
└──────────────────────────────────────────────────────────────────┘
```

- 地球居中铺满视口，初始中心 `[108°, 22°]`（亚洲/中国可见），初始 zoom ≈ 2.0（地球直径约屏高 65%）。
- 左上：极小品牌：黄色圆点 + `VISA ATLAS`（12px，字距 0.28em）+ 一行「中国普通护照 · 世界签证图谱」（9px，灰）。
- 顶部居中：搜索胶囊（宽 `min(640px, 46vw)`，高 50px，圆角 999px）。下方 8px 为预置词行（仅聚焦/空输入或有激活筛选时可见；也可常驻，保持轻量）。
- 右上：`ⓘ` 图标按钮（数据说明）。
- 左下：两行 10px 灰字提示（操作方式 + 数据规模），无边框。
- 右下：竖排玻璃控制条（+ / − / 重置），36px 按钮；下方 8px 小字 `拖拽旋转` 可省略。
- 底部居中：hover 国家时出现 **固定位置** 的小玻璃卡片（不跟随鼠标）：`日本 Japan · 免签入境 · 每次最多30天 · 点击查看档案 →`，可点击；离地 28px。点击国家或卡片打开底部抽屉。

## 3. 搜索框与预置词

- 输入框 placeholder：`搜索国家、签证类型或关键词`；左侧放大镜；右侧 `/` 提示（已聚焦时隐藏）。
- 预置词（chips，28px 高，1px 描边，hover 变黄）：
  `免签` `落地签` `电子签` `申根` `商务签` `日本` `美国` `欧洲`
  - 前 5 个是政策筛选（group/category/type），后 3 个是国家/地区查询。
  - 点击立即生效；再次点击取消；激活态 chip 为黄底黑字。
- **模糊搜索**：输入时在本地对 250 国中英文名/ISO/别名做容错匹配（忽略大小写、子串、英文编辑距离 ≤1、中文部分字序），即时显示「国家建议」；同时 300ms 防抖调用后端 `/api/v1/search`，用返回的 `items` 显示「命中 N 个目的地」列表。
- 下拉面板（宽同胶囊，圆角 16px，最大 360px 高，内部滚动）：
  - 顶部一行小字：`国家建议` 或 `命中 73 个目的地 · 用时 9ms`；
  - 行：国家中文名 + 英文名 + 右侧 ISO；第二行小字：类别 · 停留期 · `演示/线索` 角标；
  - ↑↓ 移动、Enter 选中、Esc 关闭；点击行 → 地球飞到该国 + 打开抽屉；hover 行 → 地图上对应国家高亮。
  - 无结果：`没有找到「xxx」` + 3 个预置词快捷按钮。
- 搜索生效时：命中中国家保持灰色正常亮度，未命中变暗（`#191d20`）；选中/hover 仍为黄色。

## 4. 地球交互

- 拖拽旋转（MapLibre globe 原生），滚轮/双指缩放（min 0.5 / max 10），双击放大，点击空白清除选中并关闭抽屉。
- hover 国家：该国填充变为 `#DFC11D`，边界变亮，光标 pointer；底部出现固定 hover 卡片。
- 点击国家：填充黄色（选中态）+ `map.flyTo` 到该国中心（大国家 zoom ≈3，小国/岛国 ≈6–8，微国家 8），打开底部抽屉。
- 选中态在抽屉关闭/点击空白后清除。
- 微国家（14 个无多边形）用 3–6px 灰点常驻显示，hover 变黄，点击同样打开抽屉。
- 国境线随 zoom 插值变粗；经纬网 `#1d303b`、0.6px；海洋/太空区分依赖底图背景与大气边缘，不加纹理/卫星图。
- 加载中：地球区域中央小号 `正在载入地球…` + 呼吸点；加载完成后 400ms 淡入。

## 5. 国家抽屉（Bottom Sheet）

- 位置：底部居中，宽 `min(760px, 92vw)`，圆角 20px，玻璃底；收起时高度自适应（约 240–300px），展开时最高 82vh 内部滚动。
- 收起态内容：
  - 顶行：国家中文名（Fraunces 30px）+ 英文名/ISO（灰）+ 右上关闭 ×；
  - 一行状态：黄色类别 chip（免签入境/预办签证…）+ 停留期 + 入境次数 + `重点候选` + 完整度 `45%`；
  - 一句话结论（例如「中国普通护照可免签入境，每次最多停留 30 天」）；
  - 原文摘要一行（灰，最多两行）；
  - 底部：`其他常见签证类型：商务签 工作签 留学签`（chip 可点击 → 切换商务/留学检索）+ 右侧 `展开完整档案 ↓`。
- 展开态追加：材料/费用/审核时间三块「待采集」说明（真实数据未采集，不编造）；演示明细（若有，金色 `演示样本` 标注）；来源与限制；路线编号。
- 抽屉内不出现大段说明文字；文案短、事实优先。
- 无资料国家（XK）：显示「目录内国家，本轮 249 国采集未包含」+ 关闭。

## 6. 数据说明弹层（ⓘ）

- 居中窄弹层（max 560px），只有 4 段：数据集版本/规模、来源（小组 CSV，单一来源）、资料成熟度说明（摘要级；费用/材料未采集）、免责声明。
- 关闭按钮 + Esc + 点击遮罩。

## 7. 动效与可访问性

- 地球飞行动画 900ms ease；抽屉 260ms cubic-bezier(.22,.61,.36,1)；hover 浮层淡入 120ms。
- `prefers-reduced-motion`：关闭飞行动画（jumpTo）与淡入。
- 搜索 combobox 语义、抽屉 role=dialog + aria-label、按钮 aria-label、焦点可见黄色描边。
- 键盘：`/` 聚焦搜索、Esc 关闭、↑↓/Enter 操作下拉；地图点击的等价键盘路径由搜索结果列表提供。

## 8. 实现边界

- 不再出现：左侧筛选栏、右侧结果列表、政策组图例、地图/列表切换、三栏布局。
- 保留全部后端能力（搜索/分面/国家档案），只是通过搜索、预置词与地图交互进入。
- 地图使用 MapLibre GL JS globe 投影，数据为本地 GeoJSON，无任何外部 Key/瓦片/网络请求。
