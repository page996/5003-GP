# Visa Atlas v5.0 · 极简球体地图设计规范

目标：**一屏之内只有「一个地球 + 一个搜索框」**。功能通过地图交互、搜索预置词和悬浮卡片进入，不再有三栏面板、筛选器列表和结果卡片墙。

## 1. 视觉基调

- 背景：`#05080b`（近黑），海洋 `#0e1a22`（极低饱和蓝灰），大气边缘由 MapLibre sky 自然形成。
- **颜色有含义**：陆地底色 = **旅游签政策组语义色**的低饱和版本，不再按大洲或随机分类着色：
  - 免签入境：绿 `#A0DA26`
  - 落地签：黄 `#DFC11D`
  - 电子签 / 电子授权：青 `#1DC5CE`
  - 预办签证：珊瑚 `#FF633D`
  - 特殊许可 / 属地：中性灰 `#8C9AA3`
  - 左下角常驻政策色图例，鼠标悬停图例项可看组说明与国家数。
- 国境线 `#626b72`，随缩放 0.7→1.3px；无经纬网；不使用任何地图瓦片/Key。
- **高亮层级**：
  - hover = 政策组亮色；
  - selected = 用户参考黄 `#E3C31C` + 政策组内描边/柔光；
  - **focus**：选中国家后，其余国家统一进入深灰 `#10161a` 静默态；hover 其他国家只给克制的组色提示，避免整图各自亮起、对比不足；
  - 检索未命中 = `#191d20`；命中 = 政策组淡彩。
- **装饰性 HUD**（纯 CSS，pointer-events:none）：球体外圈缓慢旋转的轨道线、四角括号、彩色微光点、品牌渐变点；让界面不显得平实，但不会遮挡地图交互。
- UI 文字：`#E8EAEC`；次级 `#8B949A`；发丝线 `rgba(255,255,255,.10)`。
- 字体：Fraunces Variable（英文/数字标题）+ Manrope Variable（UI）+ 系统中文字体；中文标题可回退到衬线（Songti SC）。
- 所有 UI 浮层：深色半透明 `rgba(9,13,16,.72)` + 12px blur + 1px 发丝线 + 大圆角。

## 2. 布局（1440×900 基准）

```
┌──────────────────────────────────────────────────────────────────┐
│ ◎ VISA ATLAS                         [ 搜索胶囊 + 预置词 ]   ⓘ  │
│                                                                  │
│                                                                  │
│                          G L O B E                               │
│                     （外圈装饰轨道 / 角标）                        │
│                                                                  │
│  ● 免签入境 ● 落地签 ● 电子签 ● 预办 ● 特殊   （hover 卡片） + − ◎ │
│ 拖拽旋转 · 滚轮缩放 · 点击国家                                     │
│ 250 个目的地 · 数据更新 2026-11                                   │
└──────────────────────────────────────────────────────────────────┘
```

- 地球居中铺满视口，初始中心 `[108°, 22°]`（亚洲/中国可见），初始 zoom ≈ 2.0。
- 左上：品牌：渐变圆点 + `VISA ATLAS` + 一行「中国普通护照 · 世界签证图谱」。
- 顶部居中：搜索胶囊（宽 `min(640px, 46vw)`，高 50px，圆角 999px）+ 8 预置词。
- 右上：`EN / 中文` 中英文切换按钮 + `ⓘ` 数据说明。语言切换覆盖品牌副标题、搜索/预置词、图例、悬浮卡、抽屉、数据说明、地图 aria/title 和页面标题。
- 左下：政策色图例 + 两行操作/数据规模提示。
- 右下：竖排玻璃控制条（+ / − / 重置）。
- 底部居中：hover 国家固定玻璃卡（不跟随鼠标），可点击打开抽屉。

## 3. 搜索框与预置词

- placeholder：`搜索国家、签证类型或关键词`；左侧放大镜、右侧 `/` 快捷键提示。
- 预置词（28px 高，1px 描边，hover 变黄，激活黄底黑字）：
  `免签` `落地签` `电子签` `申根` `商务签` `日本` `美国` `欧洲`
- **预置词统一交给后端知识图谱解析**（前端不再为每个预置词硬编码筛选字段）：
  - 国家（日本/美国）→ 国家节点，精确返回 1 国；
  - 欧洲 → 地区节点；申根 → 签证类别节点；
  - 免签/落地签/电子签 → 政策组节点；商务签 → 签证类型节点（MENTION_ONLY 线索）。
- 本地模糊建议：输入时对 250 国中英文名/ISO/别名做容错匹配（`Japn` → 日本）。
- 300ms 防抖调用 `/api/v1/search`；结果面板显示「命中 N 个目的地」以及**知识图谱命中解释**（如「知识图谱 · 国家·美国」）。
- 下拉行：国家中文名 + 英文名 + ISO；第二行 **政策组语义色点 + 类别** · 停留期 · `重点`。
- ↑↓ 选择、Enter 打开、Esc 关闭；hover 行同步地球高亮。
- 搜索生效时：命中国家按语义色淡彩、未命中变暗；选中仍为参考黄 + 政策组内描边。

## 4. 地球交互

- 拖拽旋转（MapLibre globe），滚轮/双指缩放 0.5–10×，双击放大，点击空白清除选中并关闭抽屉。
- **拖动后悬停不失效**：在空白、球体外或 UI 上松开拖拽都会清空按下状态，鼠标回到球面即可继续 hover，不需要额外点击唤醒。
- hover 国家：填充政策组亮色 + 同类边界/柔光；底部固定 hover 卡片。
- 点击国家：填充参考黄 + 政策组内描边，`map.flyTo` 聚焦；同时其他所有国家进入深灰 focus 静默态。
- 关闭抽屉/点击空白后清除选中，其他地区恢复政策组语义底色。
- 微国家（14 个无多边形）用 3–6px 政策组色圆点常驻；hover/选中放大。
- 国境线随 zoom 插值；不绘制经纬网；使用本地 GeoJSON。
- **180° 接缝**：MapLibre globe 在 180° 经线的内部接缝线用一条同海洋色、仅覆盖海洋纬带的窄线遮挡；不影响陆地、悬停或点击。
- **极区正确性**：跨 ±180° 多边形在构建期按 RFC 7946 §3.1.9 切分；南极洲保留多边形并正常渲染。

## 5. 国家抽屉（Bottom Sheet，精简版）

- 底部居中，宽 `min(760px, 92vw)`，高自适应；无展开态。
- 内容：国家名/英文名/ISO/政策组；**政策组语义色类别 chip**；停留期；入境次数；`重点候选`；一句话结论；原摘要；其他签证类型 chips；来源/路线/免责声明。
- **不出现**：费用、材料、审核时间、完整度、演示明细，以及「待采集」空位。
- 无资料国家（XK）：目录内国家、本轮未采集的明确空态。

## 6. 数据说明弹层（ⓘ）

- 居中窄弹层（max 560px）：数据集版本/规模、来源、成熟度说明（摘要级；费用/材料未采集、界面不预留空位）、免责声明。
- 关闭按钮 + Esc + 点击遮罩。

## 7. 动效与可访问性

- 地球飞行 900ms；抽屉 260ms；hover 浮层 120ms；装饰轨道缓慢旋转。
- `prefers-reduced-motion`：关闭飞行动画、淡入与装饰动画。
- 搜索 combobox 语义、抽屉 role=dialog + aria-label、按钮 aria-label、焦点黄色描边。
- 键盘：`/` 聚焦搜索、Esc 关闭、↑↓/Enter 操作下拉；地图点击的等价键盘路径由结果列表提供。

## 8. 实现边界

- 不出现：左侧筛选栏、右侧结果列表、政策组图例墙、地图/列表切换、三栏布局；图例仅为底部一条轻量色带。
- 保留全部后端能力（搜索/分面/国家档案/知识图谱），通过搜索、预置词与地图交互进入；演示明细不进 UI。
- MapLibre GL JS globe + 本地 GeoJSON，无外部 Key/瓦片/网络请求。
