# Visa Atlas v1.0 · 视觉与交互规范

目标：**「午夜制图室」**——深墨蓝底、羊皮纸金与薄荷绿点缀、衬线展示字、精密的地图刻度感。不是通用后台模板，也不要花哨动画堆砌；一屏之内要像一本可以探索的世界签证图谱。

页面外边距 16–20px，三列 gap 14px；桌面最小 1180px，≥1440px 时给中心地图更多空间。整屏不出现纵向滚动条，列内部各自滚动（细滚动条 `.va-scroll`）。

## 3. 顶部栏

- 左：几何指南针 Logo（SVG，26px，薄荷绿描边）+ 两行字：`VISA ATLAS`（Fraunces，18px，字距 0.18em）+ `世界签证图谱 · CHINA PASSPORT`（10px，`--va-text-3`，字距 0.22em）。
- 中：搜索框（宽 100%，max 640px；高 46px；圆角 14px；`--va-panel-raised`；左侧放大镜；占位文字 `搜索国家、签证类型或关键词，如「日本」「免签」「落地签」`；右侧 `⌘ K` 样式快捷键提示，实际按 `/` 聚焦）。
  - 有输入时右侧出现清除按钮。
  - 联想下拉：48px 行高，分「国家 / 签证类型 / 政策类别」小标题；键盘 ↑↓ 选择、Enter 确认、Esc 关闭。
- 右：`数据说明` 文字按钮 + 圆点状数据库状态（`SQLite · 249 条政策`，点开数据说明弹层）。

## 4. 筛选栏（左）

顶部 `筛选 FILTERS` 小标题 + 「清空」文字按钮。分组从上到下：

1. **重点候选** 开关（91 个重点目的地）+ **含演示明细** 开关（默认关，标签「演示」金色小徽章；开启时顶部出现金色提示条）。
2. **地区**：7 个代码 + 中文，两列 chip；每个 chip 右侧显示命中数；hover 时联动地图高亮该地区所有国家；点击加入筛选。
3. **政策组**：5 行列表，每行 = 颜色圆点 + 名称 + 数量；可多选；选中行底色 `rgba(255,255,255,.045)` + 左侧 2px 色条。
4. **签证类别**：可折叠（默认收起）；按组显示细分类别 chip。
5. **签证用途**：下拉（默认「旅游观光」）；非旅游类型会显示「仅类型线索」解释。
6. **停留期**：6 个 chip（含「停留期待确认」）。
7. **资料状态**：4 个 chip（完整明细 / 部分明细 / 摘要级 / 仅类型线索），带小圆点。
8. 底部：来源说明（`数据来自小组整理的 249 国 CSV`、`非官方 · 不可用于申请` 两行小字）。

## 5. 地图舞台（中）

- 面板内顶部 44px：左「世界签证图谱」标题 + 命中国家数（`128 个目的地`）；右分段控件「地图 / 列表」。
- 地图区：`position:relative; flex:1; min-height: 520px; overflow:hidden;`。SVG 世界地图按容器自适应（viewBox `0 0 1000 520`，`preserveAspectRatio="xMidYMid meet"`）。
  - 海洋：透明；经纬网：`stroke: rgba(140,180,200,.07)`，每 30°；赤道/本初子午线略亮。
  - 国家默认填充：按政策组着色时使用组色 8–12% 透明度 + `stroke: rgba(150,190,210,.22)` 0.6px；按完整度着色时用薄荷绿强度。
  - hover：该国家 path `transform: translateY(-3px) scale(1.012)`（`transform-box: fill-box; transform-origin: center;`），填充透明度 30–45%，描边变为类别色/薄荷绿、1.6px，加 `filter: drop-shadow(0 0 10px color)`；其余国家整体透明度降到 .72。
  - 选中：金色描边 2px + 外发光 + 填充 40%；国家右上角出现小圆点脉冲。
  - 搜索命中：保持正常亮度；非命中：透明度 .25（仍可点击）。
  - 微国家（面积小于阈值或没有多边形）：画 8px 圆点（带 12px 透明点击热区），hover 放大 1.4 倍；南极科考站等特殊地区使用菱形点。
  - 控件：右下角竖排缩放 +/−/重置（36px 玻璃按钮）；右上角色带切换「政策类别 / 资料完整度」两枚小按钮。
  - 图例：左下角玻璃条，颜色点 + 政策组名称（随模式切换）；右下角 `249 / 250 个目的地有资料` 迷你统计。
  - 悬停浮层：跟随鼠标偏移 14px，宽 220px；显示国家中文名 + 英文名、ISO 代码、政策组徽章、停留期、资料状态小字 `点击查看国家档案 →`；玻璃底、细边框、微箭头。
- 空态：地图仍显示，中央浮层 `没有符合条件的目的地` + `试试清空地区或停留期筛选` + 按钮。
- 地图底部留 6px 渐隐，避免与图例打架。

## 6. 右侧结果 / 档案

**结果列表**：
- 头部：`检索结果` + 结果总数（大数字，Fraunces 24px）；右侧排序下拉。
- 每条卡片高约 104px：左侧 3px 类别色条；第一行国家中文名（15px 600）+ 英文名（11px `--va-text-3`）+ 右侧 ISO mono；第二行类别徽章 + 签证用途 + 停留期；第三行摘要 2 行（12px，`--va-text-2`，超出省略）；底部细进度条表示完整度（hover 显示 `资料完整度 42%`）。
- 仅类型线索卡：金色虚线边框 + `类型线索` 徽章 + 摘要显示 `来源仅标注「商务签」等类型，结构化明细待采集`。
- 演示卡：金色 `演示` 徽章 + 右上小三角纹理；背景略暖。
- hover：translateY(-1px)、边框变亮、色条变宽；选中：薄荷绿描边。
- 分页：底部 `加载更多`（滚动触底自动加载第二页）或 `1 / 11` 页码；优先「加载更多」按钮 + 总数。
- 骨架屏 4 条；错误态、空态都要有设计。

**国家档案**（点击地图或结果后显示）：
- 顶部返回按钮 `← 返回结果`；国家中文名（Fraunces 30px）+ 英文名 + ISO + 地区 + 重点候选徽章。
- 主政策卡：类别大徽章、`requires_visa` 结论一句话（如 `中国普通护照可免签入境`）、停留期大数字、入境次数、办理渠道、`conditions_text` 原文引用块（左侧金色竖线）。
- 数据完整度环（SVG 64px）+ `摘要级资料` 说明 + `费用 / 材料 / 审核时间：待采集` 三宫格空态（虚线框 + `待采集` 小字，不要编造）。
- 类型线索：`其他常见签证类型` chip 列表（点击 → 以该类型检索）。
- 演示明细（若开启）：金色区块 `演示明细样本 · 仅用于展示字段与交互`，展示材料清单、费用、审核时间、资格规则；每条带 `演示` 徽章。
- 来源与限制：来源标题、发布方、访问日期、链接（若有）；`未经使领馆逐条核验` 警告；路线编号 mono + 复制按钮。
- 若国家无任何资料（如 XK）：显示 `目录中的国家，尚未纳入本轮 249 国采集` 空态，而不是 404。

## 7. 文案与语气

- 中文为主，英文小标签做层级（`DISCOVER / DOSSIER / COVERAGE`）。
- 不用营销夸张词；用「资料参考」「摘要级」「待采集」「仅类型线索」「演示明细」等精确词。
- 免责声明常驻页脚；演示数据开启时必须出现金色提示条。
- 数字使用等宽数字（`font-variant-numeric: tabular-nums`）。

## 8. 动效与可访问性

- 过渡 160–220ms `cubic-bezier(.22,.61,.36,1)`；地图缩放 280ms；不做视差滚动、不做自动轮播。
- 全部交互元素有 `:focus-visible` 2px 薄荷绿 outline；地图的国家点击由右侧列表提供等价键盘路径（列表项是按钮）。
- 对比度：正文 ≥ 4.5:1；小字 ≥ 3:1；颜色不作为唯一信息（徽章同时有文字）。
- `prefers-reduced-motion: reduce` 时关闭地图抬升与 pulse。

## 9. 组件命名（供多人协作）

统一使用 `va-` 前缀 BEM 风格：`.va-topbar`、`.va-search`、`.va-rail`、`.va-stage`、`.va-map`、`.va-result-card`、`.va-dossier`、`.va-badge`、`.va-chip`、`.va-switch`、`.va-skeleton`、`.va-empty`。地图内部类名用 `.va-map-*`，其样式写在 `client/features/map/map.css`，不得修改全局 `styles.css`。
