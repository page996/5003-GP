# A-B｜采集移交与交叉核验 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- A 交完整路线批次、主来源/定位、访问时间和未确认字段，草稿默认不公开。
- B 交逐项复核结果、交叉来源、冲突退回清单、可发布状态与复核日期。

## 先后和责任边界

先共同试做一条真实路线，再按 3–5 目的地滚动批次；B 退回后 A 补证据，不改变事实规避校验。

涉及文件：`data/batches/、data/templates/policy-template.json、docs/DATA.md`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

data:validate 通过；抽查每项可回溯；null 不冒充已知，不同渠道不混合；B 不重新做 API。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
