# A-C｜建库与字段变更 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- A 交表含义、完整 SQL、字典及新增字段的真实资料例子。
- C 交可运行初始化、MySQL 读写适配、兼容旧数据的迁移和接口类型。

## 先后和责任边界

A 首次建测试库后 C 接入；以后先确认字段再执行迁移，不能直接删除/重建他人库。

涉及文件：`database/schema.sql、shared/contracts.ts、server/infrastructure/mysql.ts、scripts/db-init.ts`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

中文/null/精确金额/外键往返正常；专用 MySQL 测试通过；A 的 SQL 附录同步。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
