# B-C｜数据接口、规则和更新口径 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- B 交核验批次、规则的匹配/不符/未知样例及更新要求。
- C 交统一 API、校验器/规则实现、事务备份工具和相同输入的测试结果。

## 先后和责任边界

B 先确认事实和可表达范围，C 再实现；复杂例外未支持时保持 PARTIAL，不能伪判完整。

涉及文件：`server/domain/、server/services/、shared/contracts.ts、scripts/、docs/API.md`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

空值/过期/冲突/跨币种不当通过；计划过期拒绝、失败回滚；B 不另建第二套 API。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
