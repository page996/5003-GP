# B-E｜资料措辞和推荐解释 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- B 交官方说明、术语解释、未知和冲突应怎样表达、规则用例。
- E 交页面措辞、状态显示和来源跳转样例，不自行做政策判断。

## 先后和责任边界

先基于现有字段做 UI；缺可解释字段时 B/C/E 一起确认扩展，不能把复杂说明删掉。

涉及文件：`client/features/details/、client/features/recommendation/、shared/contracts.ts`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

“需核实”不写成“可获签”；分数不写成成功率；0 与 null、有效期与停留期分别显示。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
