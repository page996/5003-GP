# C-E｜搜索与推荐 API 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- C 交 catalog/详情/推荐响应类型及错误示例。
- E 交与类型一致的表单请求、显示逻辑与未知情况体验。

## 先后和责任边界

先固定 docs/API.md；E 不直连库、不另写后端算法；改契约同步双方代码。

涉及文件：`docs/API.md、shared/contracts.ts、client/features/search/、client/features/recommendation/`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

目录搜索/筛选可组合；推荐保留个人条件和意图；输入有校验、结果有解释、无画像持久化。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
