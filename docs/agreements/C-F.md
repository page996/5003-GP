## 双方分别提供什么

- C 交必要服务端代理/环境配置及无秘密说明；如不需要额外代理写明官方依据。
- F 交官方文档、浏览器 Key 限制、实际加载/点击结果和失败样例。

## 先后和责任边界

先核对当期官方要求，再配置真实服务；目前仅预留加载器，不能认作真实高德已通过。

涉及文件：`client/features/map/MapPanel.tsx、.env.example、按需新增的服务端代理`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

安全密钥不进入 VITE 或 Git；五大区域实际验证；加载失败有回退且不伪称高德成功。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
