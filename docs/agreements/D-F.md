版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- D 提供 countries/policies/selectedCountry 和 onSelect 的总体接线。
- F 提供地图组件、资源释放、加载失败反馈与真实服务验证记录。

## 先后和责任边界

先按固定组件约定联动，再启用真实 Key；F 不改总体页面业务状态。

涉及文件：`client/App.tsx、client/features/map/MapPanel.tsx`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

地图/列表切换同一国家；刷新/卸载无重复实例；离线示意与高德状态清晰区别。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
