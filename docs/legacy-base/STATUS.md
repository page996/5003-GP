## 未完成与明确限制

1. **真实政策采集：0 条。** 当前全球目录不是已收集的签证数据库；A/B 需基于来源补齐全球主要国家、用途和主要申请渠道，负责人确认覆盖范围。
2. **真实高德服务未验收。** 未提供项目 Key，显示的是明确标注的坐标示意。C/F 需核对当前官方安全方案、必要代理、许可和全球显示能力，再实测。
3. **复杂政策规则有边界。** 当前枚举/数值/已有签证代码是基础可解释比较，不支持任意嵌套逻辑、完整法律审查、持有签证的有效期等复杂属性。无法表达的规则保持文字和 PARTIAL，不假判通过。
4. **推荐非专业结论。** 分数不是概率，也不是政府受理决定；无需或未公开的信息保留未知，不提供自动汇率换算或跨币种“最便宜”排名。
5. **覆盖指标是保守工程检查。** 官方未公布费用/处理时间可能导致完整度不能通过；应保留来源及人工覆盖账本，不编造数值凑齐。
6. **读取全目录的初版设计。** 未做大量路线的分页、性能压测、多管理员后台、自动更新、账户体系或公开生产部署加固；这些不是此次减负 base 的承诺。
7. **仓库协作尚需启用。** 代码准备在指定仓库的本地克隆内，没有擅自 commit/push；GitHub Actions 和 PR 模板已提供，但远程 CI、分支保护、成员权限尚未验证/配置。
8. **双边协议尚待认领。** 6 份职责书、15 份双边协议是交付底稿，不能代替成员本人确认、实际日期和 PR 记录。
