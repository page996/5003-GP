# A-D｜采集与建库验收 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- A 交无密码建库记录、批次范围与缺项列表。
- D 交可复现的验收结果、失败步骤和对应退回负责人。

## 先后和责任边界

先建库，再采一条真实路线，最后扩大批次；资料可信度仍由 B 复核。

涉及文件：`data/、database/、docs/COVERAGE.md`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

区分地理目录与真实路线；D 不把“有国家名”验成“政策已完成”。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
