# A-F｜国家名称与定位来源 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- A 交统一国家代码、名称、坐标和地理来源。
- F 交无法定位项、坐标/显示异常及所需补充说明。

## 先后和责任边界

F 从页面获取 countries；目录修正回到 A，不能在地图硬编码另一份代码映射。

涉及文件：`data/countries.json、scripts/generate-catalog.ts、client/features/map/`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

地图/列表使用同一国家代码；坐标未知不放在错误原点；地理来源不冒充签证来源。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
