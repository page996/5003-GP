# B-D｜真实资料发布验收 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- B 交发布版本、复核日期、来源、更新和备份记录。
- D 交 API/页面版本一致、来源可见及更新回退的验收结果。

## 先后和责任边界

B 完成人工核验再应用；D 刷新检查后记录发布，失败退回 B/C 对应责任人。

涉及文件：`data/batches/、docs/COVERAGE.md、docs/STATUS.md`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

真实、演示、待采集分开统计；未公开数据不返回前端；个人资料与秘密不进入仓库。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
