## 双方分别提供什么

- C 交接口版本、环境要求、启动命令、错误样例与测试。
- D 交统一请求封装、同源接线、全链路测试结果和具体故障报告。

## 先后和责任边界

C 先给稳定契约；D 可用 demo 接线，之后必须验证一次真实 MySQL 路径。

涉及文件：`server/app.ts、server/main.ts、client/api.ts、client/App.tsx、vite.config.ts`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

400/404/503 清晰；mysql 故障不回退 demo；运行账户不可写；build 和相关测试通过。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
