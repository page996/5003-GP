# D-E｜搜索推荐界面与总体接线 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- D 提供 catalog、选择状态、调用封装、加载/错误边界。
- E 提供组件及类型一致的回调、输入校验、详情展示和操作样例。

## 先后和责任边界

E 先独立验证组件，D 再接总页面；页面总体状态由 D 维护，E 不复制另一套。

涉及文件：`client/App.tsx、client/api.ts、client/features/search/、client/features/recommendation/、client/features/details/`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

搜索→选择→详情→推荐状态一致；清空/空结果/失败/重试可用，个人数据不写本地存储。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
