# E-F｜搜索与地图的共同样式 双边交接协议

版本：v1；状态：待双方确认。共同条款见 [README](README.md)，适用于人工与 agent 交接。

## 双方分别提供什么

- E 交搜索框/列表/选中态、详情和推荐布局需求。
- F 交地图尺寸、图例/控件位置、选中回调需求及地图限制。

## 先后和责任边界

开改共用 CSS 前划分区段，D 协调；双方只改自己组件，不整份覆盖 styles.css。

涉及文件：`client/styles.css、client/features/search/、client/features/map/`。文件主责以六人职责书为准，列出路径不代表任一方可越界整包重写。

## 接收验收

1280/1600 桌面可用；搜索与地图状态经 D 共享；不重复取数、不另造国家 ID、不追加手机适配。

交付附提交号/PR、版本、验证命令或手工步骤、至少一个失败/未知例子和剩余问题。失败由原作者修复，接收人列出复现；争议请 D 协调，不让 agent 自行猜字段。
