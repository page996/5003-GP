# F｜高德动态地图职责书

## 你要完成什么

以官方高德 JavaScript API 做一个可在桌面 Web 使用、可选目的地的简易地图，与搜索和详情联动。Base 已有 `MapPanel` 和坐标示意，不用做世界边界建模、3D、路线导航或移动端。

## 具体工作

1. 在组内项目账户申请和配置适当的 Web Key，核对来源限制与当前官方安全要求；向 C 提供服务端需求，不把安全密钥交给前端构建。
2. 真正加载高德底图、缩放拖动、国家定位点与点击；核验全球主要目的地可用范围、标注与授权限制。
3. 地图点击输出统一国家代码，接收页面当前选择；搜索选择和地图高亮保持一致。不得另建政策 API 或复制国家字典。
4. 清楚区分有资料、演示资料、待收集；“有坐标”不是“资料已核验”。
5. 加载失败或无 Key 时保留可用的目录选择并解释原因，不能把离线示意宣传为高德成功。

## 使用的组件约定

`MapPanel({countries, policies, selectedCountry, onSelect})`：国家和政策由页面提供，`selectedCountry` 为两位大写代码或 null，`onSelect(code)` 只发送代码，不返回自造政策对象。

`VITE_AMAP_KEY` 进入浏览器，必须做来源限制；`VITE_AMAP_SERVICE_HOST` 是 C/F 按官方要求配置的代理地址，代理实现不在当前 base 中。地图卸载要销毁实例/监听器，失败要有提示。

## 交付与验收

- 组件代码、无秘密的环境说明、所用官方文档与资产来源。
- 真实 Key 环境下至少亚洲、欧洲、美洲、非洲、大洋洲各一目的地的加载/点击/选择联动结果。
- 无 Key、错误 Key、网络失败三类结果；可以降级使用目录，但不记作高德通过。
- 1280×800 和 1600×1000 桌面检查，无手机验收项。

## 和谁沟通

C-F：安全服务及运行环境；D-F：页面选择与失败处理；E-F：共同样式与选中交互；A-F：国家名称/坐标来源；B-F：资料状态的含义。世界底图的可用性必须实际验证，不因有加载代码就宣称全部完成。
